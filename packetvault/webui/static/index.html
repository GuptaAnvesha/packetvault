    NMACk1,k2(m) = H(k2 ‖ H(k1 ‖ m))
    
      
    PacketVault's optional keyed layer. The custodian key yields two independent keys k1, k2. Every chain link gets a tag Tn = NMAC(n ‖ Hn), stored inside the encrypted container. Analysts who only know the case passphrase cannot forge tags, so a rebuilt chain is pinpointed to the exact packet.
    
      
    
        
        
      
    
      
    
    
    
    
    
      
    
        
    Why nest? Length-extension attack
    
        
    A prefix MAC H(k ‖ m) is SHA-256's internal state. Knowing (m, tag) and only the key length, an attacker computes a valid tag for m ‖ padding ‖ "&role=custodian".
